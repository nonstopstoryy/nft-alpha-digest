## 🔍 What makes this different

This is not another floor price tracker. Every day the AI agent analyzes:

| Signal | What we track |
|--------|--------------|
| 🐋 Holder Concentration | Top-10 whale risk, dump probability |
| 🚿 Wash Trading Score | Suspicious volume patterns |
| 😴 Dormant Wallet Activity | OG wallets starting to move |
| 🧠 Sentiment Fingerprint | FOMO vs FUD index, dead project risk |
| ⚡ Early Alpha Score | Anomalies visible 24-48h before market |
| 🔗 Cross-chain Correlation | Which collections move together |
| 📰 Narrative Momentum | AI-NFT / Gaming / RWA trend tracking |

## 🤖 How it works

1. GitHub Actions triggers every day at 08:00 UTC
2. AI agent fetches top 25 collections per network
3. Deep analysis: holder concentration, wash trading, sentiment, alpha scoring
4. Reports committed automatically to this repo
5. No server needed — runs entirely on GitHub
